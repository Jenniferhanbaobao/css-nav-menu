# CSS导航菜单实验
## 项目简介
本项目是CSS网页前端实验，实现**一级水平导航菜单**与**二级下拉导航菜单**。严格遵守实验要求：**不修改HTML标签结构，仅使用CSS完成全部页面样式**。页面模拟湖南文理学院导航栏目，包含一级菜单：首页、教学院(部)、党群机构、行政教辅机构、教学科研、招生就业、国际交流、数字图书馆；在【教学院(部)】下设置二级下拉菜单：计算机与电气工程学院、芙蓉学院。

## 技术知识点（对应实验目的）
1. **CSS选择器**：使用类选择器、子代选择器（>），精准控制各级菜单样式，避免样式污染。
2. **盒模型**：利用`padding`控制菜单内边距，扩大链接可点击区域；`margin`控制整体页面外边距。
3. **水平布局**：使用`display: flex`实现一级菜单项横向水平排列。
4. **伪类 :hover**：鼠标悬浮时，修改背景颜色；同时控制二级菜单的显示与隐藏。
5. **定位（父相子绝）**
    - `position: relative`：添加在一级菜单`<li>`，作为子元素定位参考基准，不脱离文档流。
    - `position: absolute`：添加在二级菜单`<ul>`，脱离文档流，定位在一级菜单下方。
6. **CSS继承与层叠优先级**：理解样式继承规则；当样式冲突时，选择器越具体优先级越高。

## 功能说明
### 一级菜单.html
- 导航横向水平排列，去除列表默认圆点、蓝色下划线。
- 导航栏深色背景，白色文字。
- 鼠标悬浮在菜单项，背景变为蓝色，实现交互效果。

### 二级菜单.html
- 一级菜单保持水平横向布局。
- 默认状态：二级菜单隐藏，页面只显示一级导航。
- 鼠标悬浮【教学院(部)】，自动向下弹出二级下拉菜单。
- 鼠标悬浮二级子菜单选项，同样触发背景变色交互。
- 二级菜单脱离文档流，不会挤压页面其他元素。

## 实验过程遇到的问题与解决方案
1. 问题：页面显示默认列表圆点、链接蓝色带下划线，菜单竖直排列。
   解决：添加全局重置`list-style:none`清除圆点；`text-decoration:none`取消下划线；父ul设置`display:flex`实现横向布局。
2. 问题：二级下拉菜单定位错乱，挤压页面下方内容。
   解决：给一级`<li>`添加`position:relative`，二级`<ul>`设置`position:absolute`，使用父相子绝定位，让二级菜单脱离文档流。
3. 问题：二级菜单默认直接显示，无法隐藏。
   解决：给二级ul设置`display:none`默认隐藏；使用`li:hover>ul`，悬浮时设置`display:block`显示下拉菜单。

## 优化思路

3. 提取公共CSS样式，减少重复代码，提升代码复用性。
